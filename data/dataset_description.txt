COCOYAM DRYING - MOISTURE PREDICTION USING HYPERSPECTRAL IMAGES

This dataset supports a machine-learning study of cocoyam drying. For each sample it provides a hyperspectral image (HSI) cube, the process metadata, the sample's mean reflectance spectrum, and the reference moisture content. The intended model is two-step: from the HSI cube and metadata at steps t-1 and t, it estimates the moisture content at the next step, t+1.

Files:
- hsi/ - one MATLAB .mat hyperspectral cube per sample, named {Batch}.{timestep}{slice}.mat.
- meta_data.csv - per-sample process metadata.
- y.csv - the prediction target, Moisture Content.
- wavelenghts.csv - 112 near-infrared wavelengths (nm).

Sample identifier. sample_id is written {Batch}.{timestep}{slice}. Batch is one of 16 drying batches, each under distinct drying conditions. Within a batch, timestep runs 1-11 (drying time, minutes) and slice is 1-6 (a spatial slice); 11 x 6 = 66 samples per batch and 1056 in total. Rows are ordered by batch, timestep, then slice.

Columns:
- sample_id - unique identifier.
- Reference - 1 if the sample has a measured reference moisture value; 0 if it has none and the value was imputed.
- Batch - drying-batch number (1-16).
- Time step - step index within the batch (1-11).
- Slice ID - spatial slice number (1-6).
- Drying Time - minutes since drying started (minutes).
- Drying Temp - drying-air temperature (deg C).
- AirVelocity - drying-air velocity (m/s).
- Moisture Content (y.csv) - sample moisture content (percent).

How to use it. Read a batch and slice in time order to form (t-1, t) input pairs, with the Moisture Content at t+1 as the label; train the CNN-LSTM in src/ and hold out whole batches for validation and testing.

Evaluation. Compute all accuracy metrics (RMSE, R2, RPD, etc.) only over samples with Reference = 1. Samples with Reference = 0 are imputed and must be excluded from the reported metrics.
